# Using Artifact binaries

## Prerequisites
Java JDK 17 or higher

## Download and Run
1. Click on "Actions"
2. Choose the latest run
3. Scroll down and download the Artifact (Requires Github account)
4. Open terminal (kitty, ghostty, cmd etc.) then run ```java -jar NetworkCloudDrive-0.4.19.jar```

## Configuration
For configuration create application.properties file and put it in ```./config``` folder.
